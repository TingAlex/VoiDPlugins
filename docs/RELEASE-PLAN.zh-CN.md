## 推荐演示脚本

1. 0–8 秒：展示一页已有题目或图表，启用小框，周围内容保持可见。
2. 8–20 秒：写一行；抬笔、转竖直旋钮、手回到原来的书写带，再写一行。
3. 20–30 秒：横向移动框，在原有文字旁补注；页面内容始终固定。
4. 30–40 秒：用触控板导航到文档另一处，再定位映射框继续写。
5. 40–50 秒：展示两项像素步长设置和 OTD 依赖，结束于项目入口。

如果触控板需要笔离开感应范围，应保留这一真实动作，不剪辑成可同时使用。
画面可用自制例题或无隐私笔记。最好有一个屏幕录制和一个手部俯拍。

## 对外介绍建议

中文一句话：

> 一个面向文档手写的 OpenTabletDriver 插件：用双旋钮移动笔映射区，让页面保持稳定，也让手回到习惯的书写位置。

English:

> An OpenTabletDriver plugin for document handwriting: move the pen mapping with two dials, keep the page in place, and return your hand to a preferred writing position.

首批受众可聚焦数位板笔记用户、教师批注、数学推导与 PDF 批注用户。
先展示 OneNote 实测场景，再邀请其他应用和设备用户反馈。不要把“适合所有人”
或“已证明降低疲劳/认知负荷”作为未经验证的宣传结论。

可准备 GitHub Release、OTD 社区介绍和演示视频。此清单没有代发任何社区消息，
没有改变仓库默认分支，也没有发布新 Release。
