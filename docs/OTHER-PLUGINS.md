# Other modules retained from VoiDPlugins

This repository remains a fork of [X9VoiD/VoiDPlugins](https://github.com/X9VoiD/VoiDPlugins).
The following modules are not included in the focused Precision Control ZIP.

| Module | Upstream documentation |
| --- | --- |
| MeL | [Wiki](https://github.com/X9VoiD/VoiDPlugins/wiki/MeL) |
| Reconstructor | [Wiki](https://github.com/X9VoiD/VoiDPlugins/wiki/Reconstructor) |
| WindowsInk | [Wiki](https://github.com/X9VoiD/VoiDPlugins/wiki/WindowsInk) |
| VMultiMode | [Wiki](https://github.com/X9VoiD/VoiDPlugins/wiki/VMultiMode) |
| TouchEmu | [Wiki](https://github.com/X9VoiD/VoiDPlugins/wiki/TouchEmu) |
| ScriptRunner | [Wiki](https://github.com/X9VoiD/VoiDPlugins/wiki/ScriptRunner) |

The fork includes an experimental Windows Ink `Touchpad-friendly hover`
option. It changes native pen-hover behavior and is not a universal fix for
pen/touchpad input suppression. It is not required or included in the
Precision Control package, and is not the recommended first-install path.
