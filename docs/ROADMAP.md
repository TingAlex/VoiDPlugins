## 已知限制

- 只在单屏 3840×2160、Pointer Anchored、Scale 0.25 下长期使用；混合 DPI/多屏未验证。
- 笔悬停时系统会抑制触控板，操作顺序固定为“先抬笔，再拖框”。
- 需要 Windows 精确触控板（Precision Touchpad）；普通触控板没有 PTP 报告。
- 系统三指手势应设为“无操作”，否则可能与拖框同时触发系统动作。
- 触觉相关实验不属于本仓库（属于独立的 MagicMapper 探索），不要混入插件。
