# Precision Control — TingAlex 增强版

**移动书写区，让页面留在原地。**

[English](README.md) · [安装与配置](docs/SETUP.md) · [版本记录](CHANGELOG.md) · [源码构建](docs/DEVELOPMENT.md)

这是一个面向 **Windows 文档手写场景的 OpenTabletDriver 插件**：把数位板映射到屏幕上的一个小区域，再通过两个旋钮，分别水平、竖直移动这个书写区。

你可以用触控板浏览文档，用数位板旋钮调整接下来要写的位置。写字时，页面和周围的内容保持稳定，只有标记书写区的淡色边框在移动。

这个工作流来自作者在 **Wacom PTK-670 + 触控板 + OneNote** 上的实际使用，适合连续手写笔记、在固定页面上补充文字，以及一边看题目或图表、一边在旁边书写的场景。

## 为什么需要一个可以移动的书写区？

大屏幕配合数位板时，笔在板上移动一点，屏幕上的光标就可能移动很远。缩小映射范围能让书写更精细，但固定的小范围又有另一个问题：写到后面，手会逐渐往数位板下方或右侧移动，离开自己习惯的位置。

Precision Control 让你在抬笔后移动映射区，把下一行、下一段放到更合适的屏幕位置，再让手回到舒服的书写范围。

### 页面不动，思路更容易接着走

需要继续写下一行时，不必先拖动整个 OneNote 页面。旋转旋钮，移动书写区即可。已有文字、题目和图表留在原来的位置，你可以继续沿用眼前的页面布局。

对作者而言，这减少了频繁滚动页面后重新寻找位置的打断。这是个人使用感受，尚不是经过用户研究验证的普遍结论。

### 让手回到习惯的书写位置

写完一行，抬笔，把框往下移一行左右，再把手放回数位板上熟悉的高度继续写。这样不必随着文字不断增加，让手一路向板的下边缘挪动。

向左、向右移动也一样：调整屏幕上的目标区域，给手留出更合适的活动范围。行距由你调整旋钮步长来匹配；插件不会自动识别行距或自动换行。

### 框放在哪里，位置关系看得懂

使用 **Pointer Anchored** 模式时，可以指定初始指针位于框内的哪个位置，例如靠近左上角或正中心。移动之后，数位板上的位置仍按比例对应框内的位置。

这个设计来自作者对原有精确模式的两点不满：周围页面变暗，以及框的位置受指针在整屏中的相对位置影响，需要预判。这里描述的是作者使用过的配置体验，不代表所有 Wacom 型号或驱动版本的行为。

### 周围内容保持可见

插件只绘制一圈半透明边框，不把周围页面压暗。边框不抢焦点，并允许鼠标和笔操作穿透。颜色、粗细和不透明度都可以调整。

### 浏览页面和调整书写区，各有一个直接的动作

| 想做什么 | 使用什么 | 哪个东西会移动 |
| --- | --- | --- |
| 浏览 OneNote 的其他内容 | 触控板的正常手势 | 文档页面 |
| 调整当前书写位置 | 数位板的两个旋钮 | 映射框和对应的笔映射 |
| 快速跳到新的起笔位置 | 鼠标定位快捷键 | 框重新定位到鼠标处 |

插件不接管 OneNote 的页面滚动。触控板负责应用原有的导航操作，旋钮负责书写区，两者可以交替使用。

## 一个实际的使用过程

1. 打开 OneNote，把题目或已有笔记放到合适的位置。
2. 把指针移到准备书写的地方，启用精确映射。
3. 在较小的映射范围内书写，保留完整页面作为参照。
4. 写完一行后抬笔，转动竖直旋钮，把书写区往下移。
5. 手回到数位板上习惯的位置，继续写下一行。
6. 需要到文档更远的地方时，再用触控板移动页面。

每格移动距离可以单独调节：横向和竖向不必相同。细调适合逐行书写，大步长适合快速换位置。

## 安装前先看这里

**本项目依赖 OpenTabletDriver，不是独立驱动，也不是 OneNote 插件。**

当前源码版本为 **1.1.2**，位于
[`agent/global-hotkey-precision-control` 分支](https://github.com/TingAlex/VoiDPlugins/tree/agent/global-hotkey-precision-control)。
截至 2026-10-15，公开的最新 Release 仍为 **1.0.0，不包含双旋钮功能**。在新版发布之前，请按[构建说明](docs/DEVELOPMENT.md)生成 1.1.2。

| 项目 | 当前情况 |
| --- | --- |
| 操作系统 | Windows；增强边框和全局快捷键依赖 Windows API |
| 驱动 | 必须安装 OpenTabletDriver；已在 0.6.7 上测试 |
| 作者实际使用的设备 | Wacom PTK-670，两个可独立绑定的旋钮 |
| 书写应用 | 作者在 OneNote 中使用；其他应用需要验证 |
| 手写输出 | 作者使用 Windows Ink Absolute Mode；其插件与驱动依赖需另行配置 |
| 触控板 | 可选，用于页面导航 |
| 其他数位板 | 需先确认 OTD 支持该型号，并能识别相应旋钮 |

**安装、绑定、推荐起始参数和故障排查见[安装与配置](docs/SETUP.md)。**

## 默认操作

| 操作 | 默认设置 |
| --- | --- |
| 显示或隐藏映射区 | Ctrl + Alt + Shift + P |
| 在当前鼠标位置显示或重新定位 | Ctrl + Alt + Shift + R |
| 旋钮 1 | 顺时针向右，逆时针向左，需要先绑定 |
| 旋钮 2 | 顺时针向下，逆时针向上，需要先绑定 |
| 旋钮步长 | 每格 40 个屏幕像素；横向、竖向分别可调，范围 1–1000 |

旋钮从框的当前位置开始移动，不改变框大小。没有启用映射区或正在落笔时，旋转无效，抬笔后即可继续。被忽略的动作不会在之后补执行。

## 当前边界

- 部分 Windows 硬件组合在笔悬停时会屏蔽触控板输入，可能需要把笔抬离感应区再操作触控板。插件不能保证绕过这种限制。
- 框允许移到屏幕边缘以外，尚无自动吸附或边界限制。找不到框时，可用鼠标定位快捷键重新放置。
- 1.1.2 的设置界面是中文，英文用户可以对照安装指南；尚未实现完整的界面语言切换。
- “按键平移”设置已隐藏，但内置方向快捷键仍保留。旧版自定义按键平移参数不会被此版本加载，详见安装指南。
- 多显示器、不同缩放比例和更多设备组合还需要测试。57 项自动测试覆盖功能逻辑，不代表所有硬件均已验证。
